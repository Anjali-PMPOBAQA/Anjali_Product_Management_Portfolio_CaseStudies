# 03 — User Journey & UX Flow

## 1. Journey Objective

CareerPilot AI is designed as a guided career decision journey that moves the user from initial uncertainty to a clear career direction and an actionable transition plan.

The end-to-end journey is:

**Assess → Analyze → Discover → Compare → Decide → Plan → Refine**

The product experience is intentionally structured to reduce decision complexity rather than overwhelm the user with information.

---

## 2. End-to-End User Journey

| Stage | User Goal | Product Action | User Output |
|---|---|---|---|
| Assess | Tell the product about my background | Capture experience, skills, goals, preferences and constraints | Personalized profile |
| Analyze | Understand what I bring to a new career | Analyze capabilities and transferable skills | Career-fit signals |
| Discover | Understand possible career directions | Generate relevant career options | 3 best-fit + 5 probable options |
| Compare | Understand the trade-offs | Compare selected options | Clearer understanding of alternatives |
| Decide | Choose a direction to explore | Capture preferred career direction | Selected direction |
| Plan | Know what to do next | Generate an initial transition plan | Actionable next steps |
| Refine | Improve the recommendation | Capture feedback and updated preferences | Refined career guidance |

---

# 3. Stage 1 — Assess

## User Goal

"I want the product to understand my professional background and what I am looking for."

## Product Actions

CareerPilot AI collects information about:

- Professional experience
- Current role and industry
- Skills
- Skill proficiency
- Transferable skills
- Career goals
- Work style
- Career priorities
- Work arrangement preferences
- Location flexibility
- Financial expectations
- Risk tolerance
- Other practical constraints

## Key Output

A structured user profile that can be used for career-fit analysis.

---

# 4. Stage 2 — Analyze

## User Goal

"I want to understand which parts of my existing experience and skills can transfer to other career directions."

## Product Actions

The product analyzes:

- Existing skills
- Experience
- Skill proficiency
- Transferable capabilities
- Career goals
- Work preferences
- Practical constraints

The analysis provides signals that can be used to determine potential career fit.

## Key Output

A personalized career-fit view based on the user's profile.

---

# 5. Stage 3 — Discover

## User Goal

"I want to see career options that are relevant to me."

## Product Actions

CareerPilot AI generates a focused set of career possibilities:

### Best-Fit Options

**3 primary career options**

### Probable Alternatives

**5 additional career options**

The purpose of limiting the output is to provide meaningful exploration while reducing information overload.

## Key Output

A focused set of career options relevant to the user's profile.

---

# 6. Stage 4 — Compare

## User Goal

"I want to understand how my options differ before choosing one."

## Product Actions

The user can compare career options using factors relevant to their circumstances, such as:

- Career fit
- Growth potential
- Flexibility
- User priorities
- Work preferences
- Practical constraints

## Key Output

A clearer understanding of the trade-offs between potential career directions.

---

# 7. Stage 5 — Decide

## User Goal

"I want to identify the career direction I want to explore further."

## Product Actions

The user selects a preferred career direction after reviewing the available options and comparison information.

The product captures the selected direction as the basis for the next stage.

## Key Output

A preferred career direction.

---

# 8. Stage 6 — Plan

## User Goal

"I know which direction I want to explore. Now I need to know what to do next."

## Product Actions

CareerPilot AI creates an initial transition plan based on the selected career direction and the user's existing capabilities.

The plan focuses on practical next steps required to begin the transition.

## Key Output

An initial career-transition action plan.

---

# 9. Stage 7 — Refine

## User Goal

"I want to improve or adjust the recommendation based on what I have learned."

## Product Actions

The user can:

- Review recommendations
- Provide feedback
- Modify preferences
- Update profile information
- Refine the career direction

The updated information can be used to improve future recommendations.

## Key Output

Refined and more personalized career guidance.

---

# 10. UX Screen Map

The core MVP experience is represented through the following screens:

| # | Screen | Purpose |
|---|---|---|
| 01 | Welcome & Career Goal | Introduce the product and establish the user's career objective |
| 02 | Professional Profile | Capture professional background and experience |
| 03 | Skills & Experience Assessment | Capture skills, proficiency and transferable capabilities |
| 04 | Career Preferences & Priorities | Capture goals, work style, preferences and constraints |
| 05 | Assessment Summary | Allow the user to review the information provided |
| 06 | Career Fit Analysis | Present the analysis of capabilities and career-fit signals |
| 07 | Career Options | Present 3 best-fit and 5 probable career options |
| 08 | Compare Options | Help the user compare potential directions |
| 09 | Preferred Career Direction | Capture the user's selected direction |
| 10 | Initial Transition Plan | Present practical next steps |
| 11 | Feedback & Refinement | Capture feedback and enable recommendation refinement |
